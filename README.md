# 💻 Portafolio de Desarrollo Web

Bienvenido/a a mi portafolio de desarrollo web.

Este repositorio reúne proyectos realizados durante mi proceso de formación en programación, principalmente utilizando **HTML, CSS, JavaScript, Node.js, Express, PostgreSQL y Sequelize**.

Cada proyecto representa una etapa de aprendizaje y permite observar mi evolución desde los fundamentos del desarrollo web hasta la creación de aplicaciones backend y APIs RESTful.

---

## 👩🏻‍💻 Sobre mí

Soy estudiante de desarrollo web, con interés en seguir fortaleciendo mis conocimientos en programación y desarrollo de aplicaciones.

Durante mi formación he trabajado tanto en el desarrollo **frontend** como **backend**, incorporando progresivamente nuevas tecnologías y herramientas.

Mi enfoque ha sido aprender construyendo proyectos, aplicando los conceptos estudiados y buscando comprender no solamente cómo funciona el código, sino también cómo organizar y estructurar un proyecto.

# 📈 Evolución del aprendizaje

Los proyectos presentados muestran una progresión desde los fundamentos del desarrollo web hasta la construcción de aplicaciones backend.

```text
HTML / CSS / Bootstrap
          ↓
Fundamentos de JavaScript
          ↓
JavaScript + POO + DOM
          ↓
Node.js + Express
          ↓
PostgreSQL + Sequelize
          ↓
API RESTful + JWT
          ↓
Portafolio profesional
```

Esta progresión me ha permitido incorporar gradualmente nuevas herramientas y conceptos, pasando desde aplicaciones frontend sencillas hasta proyectos con persistencia de datos, arquitectura backend, APIs y autenticación.
